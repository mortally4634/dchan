{# Apply the viewer's saved board theme BEFORE the first paint, so a page never flashes the default (Yotsuba B) theme for a moment on load or refresh. The theme is applied by main.js too, but only after the scripts run - too late, hence the flash. This runs in : it finds (or creates) the #stylesheet and points it at the saved theme, which makes the browser wait for that stylesheet before painting, like any other. Included from header.html (every normal page) and the static theme templates. #}
