{# Apply the viewer's saved board theme BEFORE the first paint, so a page never flashes the default (Yotsuba B) theme for a moment on load or refresh. main.js applies the theme too, but only after the scripts run - too late, hence the flash. This is the ONLY #stylesheet link; it is static (not created by script) so the browser treats it as render-blocking. When the saved theme differs from what is already showing, the page is hidden until that theme's stylesheet has loaded, which removes the flash even if the browser would otherwise paint the base stylesheet first. A timeout un-hides no matter what, so a missing/slow theme file can never leave the page blank. #}
